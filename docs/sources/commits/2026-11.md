# Commits without an issue: 2026-11

## `FIX - Declare the autocad-mcp server in .mcp.json.`

The user asked on 2026-11-03 that each repo's `.mcp.json` declare the MCP servers its development needs, and to
commit this with no issue link. Reviews were skipped by the user's decision.

**What changed.** `.mcp.json` gained
`"autocad-mcp": { "type": "stdio", "command": ".venv/Scripts/python.exe", "args": ["-m", "autocad_mcp.server"] }`, and
the tracked `.claude/settings.local.json` added `autocad-mcp` to `enabledMcpjsonServers`. The `qmd` entry is unchanged.

**Decisions.**

- The entry is project-level, so it works from any checkout. Rejected: a user-level registration only, because it
  does not reach other machines.
- The path is relative and holds no machine value, because Claude Code starts a project server with the project as
  its working directory. Rejected: an absolute or drive-letter path, for the same reason.
- The server is also listed in the tracked settings file, because that file is what lists this repo's enabled
  servers.

**Limits.** A checkout still needs its `.venv`, which is not tracked ([connect an agent](../../workflows/connect-an-agent.md)).
The Claude Desktop registration through `setup_claude.bat` is unchanged. The entry was checked only as far as the
server answering `tools/list`; that does not show a running AutoCAD is reachable.
